# Експертні системи на базі CLIPS

Репозиторій містить результати розробки баз знань та правил у середовищі CLIPS в рамках дисципліни «Інтелектуальні інформаційні технології».

- Група: ІН-31/2

## Структура репозиторію

- `Lab1/` – операції з фактами (assert, retract, facts), deffacts, перші шаблони і прості правила;
- `Lab2/` – створення шаблонів (deftemplate) та подання знань у вигляді фактів;
- `Lab3/` – формування бази правил (defrule) експертної системи;
- `Lab4/` – створення та використання функцій (deffunction);
- `Lab5/` – префіксна форма виразів та логічне виведення родинних відношень;
- `README.md` – опис проєкту.

Кожен файл `.clp` можна завантажити в CLIPS командою `(load "ім'я_файлу.clp")`, після чого виконати `(reset)` і `(run)`.

## Висновки

Під час виконання робіт я познайомився з оболонкою CLIPS і навчився працювати з базою фактів, створювати шаблони, правила і власні функції. Найцікавіше було робити маленькі експертні системи: діагностику рослин за симптомами і виведення родинних відношень з простих фактів.

У цій роботі я вперше створив власний репозиторій на GitHub і переніс туди код усіх попередніх лабораторних. Я зрозумів, що Git зберігає історію змін, а GitHub дозволяє зберігати проєкт онлайн, щоб він не загубився і щоб його можна було показати іншим.

Труднощі були з папками: спочатку я не розумів, як створити папку, бо окремої кнопки для цього немає. Виявилось, що Git не зберігає порожні папки, і папку треба створювати разом із файлом, написавши в назві `Lab1/README.md`. Ще довелося звикнути, що кожна зміна зберігається тільки після Commit changes, і до кожного коміту треба писати короткий опис.
