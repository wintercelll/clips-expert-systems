# Лабораторна робота 1

Знайомство з оболонкою CLIPS: операції з фактами, deffacts, deftemplate і прості правила.

- `facts.txt` – факти для завантаження командою `load-facts`;
- `lab1_days.clp` – список фактів `what-day-is-it?`;
- `lab1_rule.clp` – правило, яке виводить день тижня;
- `lab1_people.clp` – шаблон `person` і список фактів `people`;
- `lab1_people2.clp` – шаблон з `multislot`, `type` і `allowed-values`;
- `find-men.clp`, `find-women.clp`, `find-name.clp`, `find-age.clp` – правила пошуку людей.
